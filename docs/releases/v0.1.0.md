# v0.1.0 — Initial release: full admin dashboard

Date: 2026-08-14

The first tagged release of Tycoma. It ships the complete Admin Dashboard epic — the five
milestones of `tasks/tycoma-admin-dashboard-implementation-sequence.md` were delivered together
instead of as separate versions.

## Highlights

- **Foundation & access control** — single-admin setup, login, session guard (JWT httpOnly cookie,
  enforced in `src/proxy.ts`), password recovery, rate limiting, profile & change-password.
- **Core content management** — dashboard KPIs, posts, pages, categories, tags (with parent cycle
  guard), site settings and navigation menus.
- **Media library** — multi-file upload via `POST /api/media`, S3-compatible storage, media grid
  with search/filter, metadata editing, usage-guarded delete.
- **Site structure & SEO** — site settings, nested navigation menus, SEO defaults with Google
  preview, and a public `/sitemap.xml`.
- **Monitoring** — audit module with an `AuditEventWriter` port threaded through `auth`, `content`
  and `media` use cases, plus a read-only, filterable audit log viewer at `/admin/audit-log`.

## Architecture notes

- Strict hexagonal boundaries enforced: `domain/` and `application/` have zero framework imports;
  cross-module dependencies flow only through domain port interfaces wired by the framework
  composition root (`src/app/_lib/modules.ts`).
- Every external input is Zod-validated: server actions, page `searchParams`, and environment
  configuration (`src/shared/env.ts`).
- Passwords are hashed with Argon2id (`@node-rs/argon2`) through a `PasswordHasher` port — OWASP
  baseline (64 MiB, 3 passes, 1 lane, version 0x13).
